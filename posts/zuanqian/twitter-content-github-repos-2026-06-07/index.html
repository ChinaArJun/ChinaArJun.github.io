时间范围：2026-06-21 ~ 2026-07-21
整理日期：2026-07-21
数据来源：X 关键词检索、语义检索、高互动线程抓取（抽样，非全站穷举）

说明与方法#

筛选标准#

  • 近 1 个月内在 X 上被推荐、清单转发或作者自荐
  • 用途贴近自媒体 / 内容创作：视频剪辑、配音字幕、社媒发布、公众号 / 小红书、选题文案、封面图、素材下载、内容自动化、博客 Newsletter 等

局限（请先读）#

  1. 无法保证「严格 200 个互不重复且全部只关于内容创作」
    高互动帖高度重复（同一套 10 仓库列表被多人转发）；X 检索只能抽样，做不到全站穷举。
  2. 严格「近 1 个月 + 纯内容工具 + 可验证完整 URL」大约稳坐 80–130 个；扩到 ~200 会混入通用开发 / Agent / SaaS 替代清单。
  3. 部分帖只有 t.co 短链，路径按公开仓库名还原；若仓库更名，以 GitHub 搜索为准。
  4. 本清单侧重可操作收藏，不是学术完备目录。

使用建议#

  • 优先从 一 ~ 四 类开始（视频 / 发布 / 中文自媒体）
  • 五 ~ 九 为内容基建与自动化
  • 十 为同月「省订阅费」清单中的弱相关补全，按需取用
