0. 说明与方法#

收录标准#

  • 近 1 个月内在 X 上被点名推荐、出现在「apps I use / free apps / creator stack / 剪辑用什么」类讨论中
  • 形态为 iOS / Android 应用，或创作者日常当「手机 App」使用的客户端（含强移动端优先的跨端产品）
  • 用途贴近：拍剪、封面、字幕、配音、分发、平台运营、AI 写稿、素材、变现、Link-in-bio 等

局限#

  1. X 检索为抽样，无法穷举；高互动帖高度同质（CapCut / Canva / Instagram Edits 反复出现）。
  2. 严格「帖子里写出完整 App 名」约数十～百余个；扩到 200 会纳入同月创作者栈中的移动端常客（帖中可能只写产品名）。
  3. 部分产品以 Web 为主、App 为辅，表中标注 移动优先 / 跨端 / 有官方 App。
  4. 中文剪映与 CapCut 为同源产品线，分列；地区商店名称可能不同。

字段说明#

字段含义
平台iOS / Android / 双端 / 跨端
X 热度高 = 近月多帖点名；中 = 工具栈出现；低 = 补全常客

6. 风险与注意#

  1. 订阅疲劳：CapCut Pro、素材库、AI 额度叠加易破 50–50–50–200/月。
  2. 水印与导出限制：免费层常限分辨率/水印，发商业内容前看授权。
  3. 隐私：人脸/克隆音色类 App 注意素材是否用于训练。
  4. 地区版：剪映/CapCut、抖音/TikTok 功能与商店包不同。
  5. 开源 App：OpenCut 等仍在快速迭代，生产环境请先小规模试用。
